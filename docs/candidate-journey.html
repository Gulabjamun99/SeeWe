👤 Candidate Journey — Har Feature Ka Poora Breakdown

SeeWe AI portal par candidate ko signup se lekar offer tak kya-kya karna hota hai, screen par kya dikhta hai, aur har feature andar se kaise kaam karta hai.

1

Account Banao — Sign Up / Login

Entry point: header ka "Sign Up" button
Kya dikhta hai
  • Sign-up form: Full name, Email, Password (role automatic = CANDIDATE)
  • Login screen purane users ke liye — email + password
  • Signup ke turant baad seedha Candidate Dashboard khulta hai
  • Demo account bhi available: Arjun Mehta (arjun.mehta@gmail.com)
Kaise hota hai
  • Form submit → POST /api/auth/login → user DB me CANDIDATE role ke saath create
  • Session + profile Zustand store me load hota hai (refresh par bhi stay)
  • Email invalid / duplicate → inline error message
  • Notification bell + email system isi account se jud jata hai
Sign Up form→Account create (CANDIDATE)→Dashboard open

👤Profile
Kya dikhta hai
  • Profile Strength meter — % complete + nudges ("Add skills to reach 100%")
  • Form: name, phone, headline, skills chips, experience, education, preferred locations, salary expectation, notice period (Immediate / 15d / 1m / 2m / 3m)
  • CV Upload card — PDF/DOC attach
  • AI Resume Parser — CV upload karte hi AI fields auto-fill karta hai
  • Video Resume card — 60–90 sec camera se record/upload
Kaise hota hai
  • Har edit → Save → dirty-state check, validation toasts, turant persist
  • CV upload → /api/resume/parse → AI skills/experience nikaal kar profile me daal deta hai (1-click accept)
  • Video resume → /api/candidates/video-resume par store hota hai, recruiter profile me dikhta hai
  • Strength % live update hota hai — deep-link "Complete now" button
3

Jobs Dhoondo Aur Apply Karo — Home / Jobs

Browse, search, save, recommended, easy-apply
Kya dikhta hai
  • Jobs grid — card me: title, company, salary range, location chip (REMOTE / HYBRID / ONSITE), posted time, ACTIVE badge
  • Recommended Jobs — AI match % (profile skills vs JD)
  • Search bar + filters (department, location type, salary)
  • Job Detail popup: full description, requirements, Apply Now, 🔖 Save
  • Applied job par "✓ Applied" badge — duplicate apply block
Kaise hota hai
  • GET /api/jobs (ACTIVE jobs) + /api/jobs/recommendations AI scoring
  • Easy Apply dialog: profile confirm + cover note + CV attach → POST /api/applications → status NEW
  • Save → /api/saved-jobs → Saved tab me list
  • Apply ke baad recruiter ko response dashboard me row dikhti hai; candidate ko notification
  • 🔔 Job Alerts subscribe — naya matching job → bell + email alert
Browse / Search→Job Detail→Easy Apply→Application NEW + ✓ Applied badge
4

Application Track Karo — Applications Tab

Har application ki live 6-step timeline
Kya dikhta hai
  • 14-Day Response Promise banner — SLA cross hone par honest reminder notice
  • Application card: job title + company + status pill + applied date
  • Timeline: Applied → Viewed → Shortlisted → Interview → Offer → Hired — completed nodes ✓, current node pulsing
  • CV attached indicator, recruiter "Viewed" signal
  • Reject hone par honest red state
Kaise hota hai
  • GET /api/applications?candidateId → har card ka status DB se
  • Recruiter job dekhe → "Viewed" ✓ auto mark; shortlist/status change → timeline aage
  • Status change → Notification + Email candidate ko
  • SLA sweep 14 din se purani application par reminder trigger karta hai
5

Skills Verify Karo — Skills Tab

Assessment + ATS Simulator + Role-Fit Deep Dive
🛡️ Assessment CenterAI skill quiz (role-wise MCQ) do → verified skill badge milta hai jo recruiter ko dikhta hai. Score sirf verification ke liye — verdict candidate ke control me share hota hai.
📊 ATS SimulatorResume/JD paste karo → ATS-friendliness score, missing keywords chips, format issues + fix suggestions. Ye candidate ka PRIVATE preparation tool hai.
🎯 Role-Fit Deep DiveAI kisi bhi role ke liye fit % nikalta hai — strengths, gaps, learning path recommend karta hai. Candidate apni prep plan bana sakta hai.
6

🎤 Interview Invite → AI Interview Room

Shortlist hone par recruiter "Send AI Invite" bhejta hai — email + notification aata hai
Kya dikhta hai
  • Dashboard par pulsing CTA: "Take AI Interview 🎤" — subtitle: "Invite received — answer voice & typed questions set by the hiring team"
  • Welcome screen: "How this interview works — 🎤 3 spoken + ⌨️ 6 typed" jaisa summary
  • Left card: AI Interviewer avatar + soundwave animation + question text card (format chip ke saath)
  • Top bar: job name + question counter + ⏱️ countdown timer (recruiter-set, amber pulse last 30s me)
  • Exit karke aao to "Resume AI Interview" banner wait karta hai
Kaise hota hai
  • Recruiter invite → /api/interview/invite → unique interview PENDING + email (INTERVIEW_INVITE) + notification
  • Candidate open kare → /api/interview/start → PENDING → IN_PROGRESS (sirf candidate hi trigger kar sakta hai)
  • AI bolta hai (TTS): male voice "jam" @ speed 0.85 — clear, slow Indian accent + soundwave animate
  • Answer /api/interview/answer par save; ASR voice ko transcript banata hai

Practice Tab — Private AI Mock Interview

Jab chahe, jitni baar — koi invite nahi chahiye
Kya dikhta hai
  • Role/topic choose karo → AI interviewer same room experience (voice + text)
  • Har answer ke baad personal feedback — improve karne ke tips
  • "Private practice" label — clear indication ki ye sirf candidate ka hai
Kaise hota hai
  • /api/ai/mock-interview question generate karta hai, /submit feedback deta hai
  • 🔒 Mock practice data KABHI recruiter/client ko expose nahi hota — API layer par candidate-only
  • Real interview se bilkul alag — confidence build karne ka safe space

Community & Extra Tools

Guilds · Alerts · Salary Insights · Notifications
👥 Guilds HubReferral communities join karo — posts, replies, insider referrals. Candidate apna profile guild me showcase kar sakta hai.
🔔 Alerts + Chat FeedJob alerts chat-style feed me dikhte hain — naya matching job, status changes, interview reminders sab ek jagah.
💰 Salary InsightsRole-wise salary benchmarks dekho — negotiation prep ke liye. Plus notification bell + email digest settings.

🔒 Privacy Rules — Candidate Ko Ye KABHI Nahi Dikhta

  • ❌ AI evaluation score (overall ya breakdown — technical/communication/etc.)
  • ❌ Recruiter ka shortlist verdict ya screening dossier
  • ❌ Proctoring flags, leaderboard position, recruiter internal notes
  • ❌ Client-side feedback ya shared-with-client reports ka content
  • ✅ Candidate ko sirf status timeline (Applied → Viewed → Shortlisted → Interview → Offer → Hired) + notifications dikhte hain
  • 🛡️ Ye sab API layer par enforce hai — candidate role ke requests ko ye data return hi nahi hota, sirf UI hide nahi kiya jata
